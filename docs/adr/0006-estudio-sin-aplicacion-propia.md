# El estudio es una carpeta con skills, sin aplicación propia

El estudio es una carpeta de trabajo (una subcarpeta por episodio, con su contenido, guion, fuentes, lista de planos y exportación), más unas skills que el usuario maneja hablando con Claude Code. No se construye una aplicación con pantallas, botones ni línea de tiempo. Una aplicación serían meses de trabajo que no mejoran el episodio, y el plan base demuestra que el formato se produce entero desde el agente. Se empieza con un solo formato (el diálogo perro–tutor en vertical), pero cada formato es una "receta" separada, para que añadir otro no obligue a rehacer el estudio.

## Opciones consideradas

- **Aplicación propia con interfaz**: rechazada por ahora. Si llega a hacer falta (por ejemplo, para que otras personas usen el estudio), se construye encima de esta carpeta.
